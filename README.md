# 🍳 私房菜单

一个记录**在家做的每一顿饭**的纯前端网站：拍下成品、勾选做的菜、写句感想，攒出属于你的做饭日记。菜谱管理和「今天吃什么」随机抽取依然是核心能力。

**零依赖、零后端**，所有数据存在浏览器本地（IndexedDB，容量远超 localStorage 的 5MB 限制）。界面为 iOS 极简风格：大标题导航、分组圆角卡片、毛玻璃 Tab 栏。

## 功能

- 🍚 **饭记**（核心）：记录每顿饭 = 成品照片（可选）+ 从菜谱勾选做的菜（可不选）+ 一句感想（可选）。按日分组的时间线（今天/昨天/日期），点菜名直达菜谱
- ✅ **自动打卡**：保存饭记自动点亮「好好吃饭」日历当天；日历支持翻月、补打过去、连续天数统计
- 🏠 **首页**：问候 + 今日饭记摘要卡（今天几顿、最近一餐）+ 打卡日历 + 「今天吃什么」快捷卡 + **时令推荐轮播**（内置时令库按月份匹配，高清实拍大图，自动播放可滑动）
- 📖 **菜单**：菜谱库——图片（上传自动压缩）、食材、步骤（**拖拽排序**）、标签、分类、1~5 颗心喜爱度、搜索（菜名/标签/食材）
- 🎲 **抽签**：等概率 / 按喜爱度加权，支持按分类抽，带名字轮播动画
- ⚙️ **我的**：存储统计、持久化存储、PWA 安装、导出 / 导入备份、清空、图片致谢
- 🍳 首次打开自动注入 5 道经典家常菜示例（配真实照片，可自行删除，不会重复出现）
- 🖼️ 内置照片来自 Wikimedia Commons 免费授权作品（许可致谢见「我的」页）
- 响应式：电脑左侧导航栏，手机底部毛玻璃 Tab 栏（5 Tab）

## 本地使用

双击 `index.html`，用浏览器打开即可，无需安装任何东西。

## 部署到公网（手机在外也能访问）

数据是**按网址隔离**的：本地打开（`file://`）和部署后的网址是两份独立数据，互不影响。

### 方式一：GitHub Pages（免费）

1. 在 github.com 新建一个仓库（如 `sifang-caidan`）
2. 把本文件夹推到仓库：`git init && git add . && git commit -m "私房菜单" && git remote add origin <仓库地址> && git push -u origin main`
3. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

### 方式二：Cloudflare Pages（免费，国内访问一般更稳定）

1. 登录 dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets
2. 把整个文件夹拖进去部署即可，会得到一个 `xxx.pages.dev` 地址

## 安装成应用（PWA，推荐）

网站支持「安装到桌面/主屏幕」，像 App 一样使用，还有两个好处：

1. **自动获得持久化存储**：浏览器不再在磁盘紧张时清理数据（「我的」页会显示 ✅）
2. **断网也能打开**：看过的内容有离线缓存

安装方法：

- **Android 手机**：Chrome/Edge 打开网站 → 右上角菜单 ⋮ → 「安装应用 / 添加到主屏幕」
- **iPhone/iPad**：Safari 打开网站 → 分享按钮 → 「添加到主屏幕」
- **电脑 Chrome/Edge**：地址栏右侧的「安装」图标（⊕ 或小显示器图标）→ 安装

## ⚠️ 数据注意事项

- **数据在浏览器里，不在网站里**：换浏览器/换设备，数据都不会自动跟过去。
- **跨设备手动同步**：旧设备「我的」页 → 导出备份 → 把 JSON 文件发到新设备 → 「我的」页 → 导入备份。
- **存储容量**：使用 IndexedDB，配额由浏览器按磁盘空间动态分配（Chrome 最高可达磁盘空闲空间的约 60%，通常几百 MB ~ 几 GB）。实际配额在「我的」页有实时显示。
- **持久化存储**：浏览器只授予「已安装成应用」的网站。安装后自动获准，浏览器不会在磁盘紧张时清理数据。即使未安装，数据一般也不会被清理。
- **清缓存注意**：清除浏览器的「缓存」一般不影响数据；但清除「Cookie 和网站数据」会连数据一起删，定期导出备份依然是好习惯。
- **自动打卡规则**：保存饭记 = 当天打卡；删除饭记或手动取消打卡互不影响。手动取消后当天再存饭记会重新打卡（预期行为）。
- 旧版数据会自动迁移，无需手动处理。
- 首次从本地切到线上地址时，用「导出 → 导入」把数据迁移一次。

## 文件结构

```
index.html        页面骨架：侧栏/底栏 5 Tab 导航 + 8 个视图
style.css         全部样式（想换配色改文件顶部的颜色变量即可）
manifest.json     PWA 声明（安装成应用用）
icon-192.png      应用图标（192 / 512）
icon-512.png
sw.js             离线缓存（Service Worker）
images/           内置照片（Wikimedia Commons 免费授权，已压缩）
js/content.js     内置内容：示例菜谱 + 时令推荐库 + 照片致谢 + 占位图生成器
js/checkin.js     打卡与饭记的日期逻辑（日历/连续天数/时间线分组）
js/store.js       数据层：IndexedDB 读写 + 菜品/饭记/打卡 CRUD + 迁移与注入
js/image.js       图片压缩
js/random.js      抽签算法 + 轮播动画
js/app.js         界面层：视图切换、渲染、表单、事件
tests/            冒烟测试（node tests/smoke-node.js）+ 本地服务器（node tests/serve.js）+ 端到端（node tests/e2e.js）
```
